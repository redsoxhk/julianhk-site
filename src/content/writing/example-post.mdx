## Regular writing works normally

Most of a post is just text. You write it in Markdown, which means `**bold**`
gives you **bold**, `_italic_` gives you _italic_, and a line starting with `##`
becomes a heading. Links work the way you'd expect: [the home page](/).

## You can drop components into the middle of a post

This is the part plain Markdown can't do. Because this is an **MDX** file, any
component from `src/components/` can be used right inside the writing:

<Callout title="Small batch, no preservatives" heat={4}>
  This box is a real component — `Callout` — imported at the top of this file. It takes a
  `title` and an optional `heat` from 1 to 5, which tints the left edge and adds the meter.
</Callout>

The heat meter itself is reusable too, so a list of ratings can appear inside a
post exactly as it does on the home page:

<HeatList
  items={[
    { name: 'Habanero', heat: 4 },
    { name: 'Jalapeño', heat: 2 },
    { name: 'Bell pepper', heat: 1 },
  ]}
/>

## Images

Images go in `src/assets/` and get imported at the top of the file. Astro resizes
and compresses them automatically and writes the width and height into the page,
so nothing jumps around while it loads.

## Code

Code blocks are syntax-highlighted with no setup:

```js
const heat = (scoville) => Math.min(5, Math.ceil(scoville / 200_000));
```

## Starting a real post

Copy this file, rename it — the filename becomes the web address, so
`first-batch.mdx` lands at `/writing/first-batch/` — and replace the block at
the very top:

```yaml
---
title: 'Your title'
description: 'One sentence. Shows on the writing index and in link previews.'
date: 2026-08-01
draft: true
---
```

Leave `draft: true` while you're still working. Drafts don't appear on the
writing page and don't get published — flip it to `false` when it's ready.
